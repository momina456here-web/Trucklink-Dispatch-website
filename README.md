# 🚚 TruckLink Dispatch Website

A professional truck dispatch service website built using HTML, CSS, Bootstrap, and JavaScript.

---

## 📌 Features
- Responsive design (mobile friendly)
- Hero section with slideshow
- Services section
- Pricing plans
- Contact form
- About page
- Floating call button

---

## 🛠️ Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

---

## 📂 Project Structure

/image → all images
index.html → Home page
about.html → About page
services.html → Services page
contact.html → Contact page
style.css → Main styling
script.js → JavaScript


---

## 🚀 How to Run
1. Download project
2. Open `index.html` in browser
